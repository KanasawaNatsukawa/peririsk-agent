## 推荐方案：教室电脑 + U 盘

主方案使用教室讲台电脑或老师电脑，U 盘携带完整演示包。平板只作为备份播放器。

### U 盘内容

- `slides.pdf`：最终汇报材料，PDF 不怕字体和排版变化；
- `demo.mp4`：可选的 Agent 轨迹录屏；没有它也能用 PPT 截图完成演示；
- `code-screenshots/`：`peririsk_agent.py`、`asa_risk.py`、`evaluate.py` 的关键代码截图；
- `evaluation_results.csv`：可现场打开的评估结果；
- `README_DEMO.txt`：一页纸说明“先打开什么、备用文件在哪”；
- `asa_risk.py`、`heartbeat_demo.py`：不调用 API 的本地演示脚本；
- 平板充电线、USB-C 转 HDMI 转接头、普通 U 盘备份。

不要把 `config.py` 和 API Key 放进 U 盘。

## 演示顺序

### 1. 先用 PPT 讲问题与架构（1–2 分钟）

讲清楚：大模型负责调度，ASA 和心率由本地确定性代码计算。

### 2. 现场运行不依赖 API 的代码（1–2 分钟）

如果讲台电脑有 Python：

```bash
python asa_risk.py
python heartbeat_demo.py
```

这两段能证明规则引擎和波形处理是真正本地运行的，不依赖大模型。

### 3. 播放 Agent 完整流程录屏（1–2 分钟）

录屏展示：

- 查病历；
- 分析波形；
- ASA 分级；
- 生成三段式报告；
- 每段结论带“依据”。

这样既能看到完整 Agent，又不受现场网络和 API Key 影响。

### 4. 代码讲解（30 秒）

只讲三处：

- `get_patient_record` 的字段白名单；
- `analyze_waveform` 的 `find_peaks`；
- `assess_asa` 的规则优先级和血压地板。

不要现场逐行读代码。
