# 组会演示双方案

## 总原则

- **A 方案**：平板远程宿舍台式机，现场操作真实代码和运行过程。
- **B 方案**：教室电脑 + U 盘，播放 PDF、截图和录屏，必要时运行不依赖 API 的 ASA 脚本。
- 13:30 做一次切换判断。A 方案只要出现卡顿、模糊、掉线或无法全屏，就直接切 B，不在台上调试。

## A 方案：平板远程宿舍台式机

### 宿舍台式机提前准备

1. 安装并登录远程工具（ToDesk、Parsec 或 Moonlight/Sunshine 任选一个，优先选你实际测过最稳的）。
2. 设置无人值守访问和固定密码；不要依赖临时确认。
3. 电源设置为“高性能”，关闭睡眠、休眠、屏幕保护和自动更新重启。
4. 关闭微信、QQ、邮件和系统通知，开启专注助手。
5. 分辨率设为 1920×1080；终端和编辑器字号放大到 150%。
6. 提前打开并摆好窗口：
   - 最终 PDF，全屏；
   - PowerShell，工作目录为 `demo_package\code`；
   - `peririsk_agent.py` 第 220–276 行；
   - `asa_risk.py`；
   - `ui_thinking.png`、`ui_report.png`；
   - `evaluation_results.csv`。
7. 提前跑一次 `python demo_asa_cases.py`，确认终端输出和字号。
8. 不要把 API Key 或 `config.py` 放到共享目录；远程会话只由你本人操作。

### 平板提前准备

1. 安装同一个远程工具客户端，登录同一账号。
2. 准备 USB-C 转 HDMI 转接头，测试平板直接接投影。
3. 平板充电到 80% 以上，带充电线。
4. 正式组会前在教室同一网络环境测试一次，不要只在宿舍测。

### 网络

- 优先测试平板和台式机都连校园网。
- 如果校园网限制远程桌面，平板改用手机热点；台式机保持宿舍网络。
- 手机热点和充电宝充满电。

### A 方案失败触发条件

出现任一情况就切 B：

- 远程延迟明显，鼠标和画面不同步；
- 终端文字在投影上模糊；
- 5 分钟内掉线两次；
- 无法把远程窗口全屏；
- 平板接投影后比例异常或黑屏。

## B 方案：教室电脑 + U 盘

### U 盘内容

- `demo_package/`
- `data_aligned/`
- `PeriRisk Agent 组会汇报_最终版.pdf`
- `ui_thinking.png`
- `ui_report.png`
- 60–90 秒完整 Agent 录屏（如果有）
- 一页现场操作卡

### 教室电脑使用顺序

1. 先打开 PDF，确认投影比例。
2. 需要代码演示时，进入 `demo_package\code`：

```powershell
python demo_asa_cases.py
```

3. 如果提示找不到 Python，直接放 `ui_thinking.png` 和 `ui_report.png`，播放录屏。
4. 不在讲台电脑上安装 Python、scipy 或输入 API Key。

## 两种方案共用的 3 分钟内容

1. 讲问题和架构：大模型决策，本地计算。
2. 现场跑 `demo_asa_cases.py`：四个 ASA 结果。
3. 打开 `peririsk_agent.py`：`messages`、`tool_calls`、本地执行、`tool_call_id` 回填。
4. 展示完整 Agent 截图或录屏：思考轨迹 + 三段式报告。
5. 说明限制：单例、单窗口，不能代表多患者 MAE。
