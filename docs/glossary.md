# PeriRisk 术语表

> 规则：代码里的英文标识符保持原样，旁边用中文解释。第一次出现时标注，后面可以只写英文。

## 最常用

| 英文 | 中文 | 在项目里是什么 |
|---|---|---|
| Agent | 智能体 | 会自己决定下一步、调用工具的程序 |
| LLM | 大语言模型 | 负责理解任务、选择工具、写报告 |
| API | 接口 | 程序与外部服务通信的入口 |
| Function Calling | 函数调用 | 大模型用固定格式请求本地执行函数 |
| tool | 工具 | 一个普通 Python 函数，例如查病历、算心率 |
| tool_call | 工具调用请求 | 大模型说“请执行这个工具” |
| tool_calls | 工具调用请求列表 | 一次可能请求多个工具 |
| tool_call_id | 工具调用编号 | 用来把“请求”和“结果”配对的编号 |
| messages | 消息列表 | 一整段对话记录 |
| role | 角色 | 这条消息是谁说的：系统、用户、助手、工具 |
| content | 内容 | 消息里的正文 |
| system prompt | 系统提示词 | 给大模型的固定工作规则 |
| user | 用户 | 发起任务的一方 |
| assistant | 助手 | 大模型这一方 |
| loop | 循环 | 重复“问模型→执行工具→回填结果” |
| callback | 回调函数 | 每发生一件事就通知外部一次 |
| on_event | 事件回调 | 本项目的回调函数名 |
| fallback | 兜底方案 | 主方案失败时使用的备用方案 |
| error | 错误 | 程序执行失败时返回的信息 |

## 代码与数据

| 英文 | 中文 | 在项目里是什么 |
|---|---|---|
| function | 函数 | 一段可重复执行的代码 |
| parameter / argument | 参数 | 调用函数时传进去的值 |
| return | 返回 | 函数执行完交出的结果 |
| variable | 变量 | 保存数据值的名字 |
| list | 列表 | 有顺序的一组数据，例如 `messages` |
| dict | 字典 | 键和值配对的数据，例如患者档案 |
| key / value | 键 / 值 | 字典里的名字和对应内容 |
| string | 字符串 | 一段文字 |
| integer | 整数 | 没有小数点的数字 |
| boolean | 布尔值 | 只有 `True` 或 `False` |
| None | 空值 | 表示“没有提供” |
| JSON | JSON 数据格式 | 一种人和程序都能读的结构化文本 |
| schema | 模式 / 说明书 | 告诉模型工具需要哪些参数 |
| payload | 请求数据包 | 发给 API 的完整数据 |
| response | 响应 | API 返回的数据 |
| import | 导入 | 把别的文件里的函数拿来用 |
| CLI | 命令行界面 | 在终端里运行程序 |
| Web UI | 网页界面 | 在浏览器里操作程序 |
| CSV | 逗号分隔值 | 可以用 Excel 打开的表格文件 |
| MAE | 平均绝对误差 | 多个误差绝对值的平均数 |

|---|---|---|
| ASA | 美国麻醉医师学会分级 | 本项目用简化规则计算 I–V 级 |

| scipy | 科学计算库 | `analyze_waveform` 用它寻找波峰 |
| DeepSeek | 深度求索模型 | 项目调用的中文大模型服务 |
