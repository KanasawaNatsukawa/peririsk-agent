## 重要修正

- 旧 PPT 的 Horvath 2021 DOI `10.1097/ALN.0000000000003967` 实际对应麻醉碳足迹论文。
- 本版不再引用这篇付费墙文章，ASA 结论改由 Sankar 2014 和 Karim 2021 两篇开放全文支撑。
- 旧的时间数字 20–40 分钟不再使用；改为 Zhang 2021 系统综述中的“节省 24–137 分钟/患者”。

## 现场使用

老师问到某条引用时，直接打开对应的 `pdf/*.pdf`，搜索论文中的 `Results`、`Discussion` 或表格中的对应数字即可。PDF 是 Europe PMC 全文 XML 的阅读版，内容来自开放获取原文。
