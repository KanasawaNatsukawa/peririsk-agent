# 3 分钟演示录屏脚本

这是可选方案。组会现场直接播放 PPT、运行 `demo_asa_cases.py`、展示 PPT 里的界面截图即可；只有当你想额外准备一份完整 Agent 兜底视频时，才需要录。

录制建议：在宿舍台式机上用 PowerPoint“录制幻灯片演示”或系统录屏，分辨率 1920×1080，鼠标移动放慢。录完把文件放到 `video/`。

## 0:00–0:20 开场

“这是 PeriRisk，围术期麻醉风险评估 Agent。它不把关键计算交给大模型：大模型负责决定调用哪个工具，ASA 分级和心率由本地代码计算。”

画面：标题页。

## 0:20–0:50 问题与架构

“输入是患者病历和一段脉搏波。Agent 需要查病历、算心率、算 ASA，再生成三段式报告。这里的关键设计是可解释和可复现。”

画面：架构页，指出三个工具。

## 0:50–1:40 现场代码演示

“先看 ASA 规则。它先按基础疾病定级，再用血压地板向上抬，最后取较高值。”

画面：打开 `code/demo_asa_cases.py`，在终端运行：

```powershell
python demo_asa_cases.py
```

口头解释两个结果：

- 50 岁、血压 146：基础 I，地板 II，最终 II。
- 82 岁、病情不稳定：直接 V，不会被后面的规则覆盖。

## 1:40–2:30 Agent 轨迹

“完整 Agent 会先查病历，再分析波形，最后调用 ASA 工具。每一步都由本地执行，结果通过 `tool_call_id` 回填。”

画面：播放 Agent 录屏或 `assets/ui_thinking.png`，鼠标依次指过病历、心率、ASA 三步，再切到 `ui_report.png`。

## 2:30–3:00 结果与边界

“当前 5 个病例的 ASA 都是规则一致性检查，不是临床准确率。心率误差 5.7 来自同一份波形，是单例对照，不是 5 位患者的平均。下一步先补波形 ID 和多患者波形，再做参数优化。”

画面：`data/evaluation_results.csv` 和最后一页。

## 录制时不要做的事

- 不展示 API Key。
- 不打开需要联网的 Streamlit 页面作为唯一画面。
- 不逐行读代码，只讲输入、规则和输出。
- 不把 5.7 说成“5 位患者平均误差”。
