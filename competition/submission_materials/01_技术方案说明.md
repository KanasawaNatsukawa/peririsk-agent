# PeriRisk Agent 技术方案说明

## 一、作品定位

**围术期风险评估助手 Agent（PeriRisk Agent）**：面向麻醉科医生与围术期团队，输入患者结构化病历与监护波形（PPG），输出 ASA 风险分级与三段式术前评估报告（风险评估 / 麻醉关注点 / 建议）。

解决的真实问题：术前风险评估目前全流程依赖医生人工——手工翻病历、逐项核对 ASA 分级并对照指南，单次约 20–40 分钟，易漏项、存在主观偏差；基层医院麻醉医生短缺，评估规范性压力更大。PeriRisk 的切入点是把这个环节自动化、标准化：由大模型自主调度工具链，输出带依据、可追溯、可复现的评估结论。

## 二、技术架构（三层）

整体设计原则：**大模型决策 + 本地计算**。数值计算与规则判定在本地完成，不依赖模型"猜测"。

### 应用层 · Agent 主循环
- 大模型（DeepSeek）通过 Function Calling 自主拆解任务、调用工具、回填结果；
- 内置 **10 轮对话安全阀**，防止循环失控或空转；20 例实测最长使用 7 轮。

### 工具层 · Function Calling 工具链
| 工具 | 功能 | 实现方式 |
|---|---|---|
| get_patient_record | 病历查询（年龄、病史、BMI、急诊和气道信息） | 本地患者档案 |
| validate_case_data | 检查病历字段、缺失值、异常值和波形质量 | 本地数据质量规则 |
| analyze_waveform | 从 120 秒 PPG 中自动选出稳定 60 秒并计算心率 | Python(scipy) 本地信号处理 |
| compare_hr_windows | 比较 30/60 秒窗口并判断稳定性 | 本地确定性计算 |
| assess_asa_grade | ASA 分级规则引擎 | 本地规则判定（纯逻辑，不调 AI） |

### 数据模型层
- 大模型：DeepSeek API（提示词、模型名、接口地址统一在 llm.py 一处维护）；
- 数据：20 个 VitalDB 公开生理病例，每个 120 秒脉搏波、500Hz；
- 计算：Python + scipy（波形峰值检测、心率计算）。

## 三、防幻觉机制

1. **字段白名单**：系统提示词限定模型只能引用工具真实返回的字段（如年龄、既往史、收缩压、算法心率、ASA 分级），工具未返回的信息（性别、舒张压、造影结果等）一律不得写入报告，从机制上防止编造病历。
2. **结论附依据**：报告每一条结论句末标注"（依据：…）"，指明引用了哪个工具的哪个返回值。
3. **10 轮安全阀**：Agent 循环超过 10 轮强制收敛并输出当前可用结论。

## 四、运行与演示方式

- **命令行 Agent**：`python peririsk_agent.py`（可带提示词参数）；
- **Web 界面**：`python -m streamlit run app.py`（浏览器选患者、逐行查看思考过程与报告）；
- **离线批量评估**：`python evaluate.py`（对 20 个测试病例跑 Agent，导出 `evaluation_results.csv`）。
- **候选窗口与参数评估**：`python evaluate.py --windows-only` 和 `python evaluate.py --tune-heart-rate`，均不调用大模型。
