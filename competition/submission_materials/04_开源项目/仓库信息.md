# 开源项目信息

## GitHub 仓库

- 仓库地址：https://github.com/KanasawaNatsukawa/peririsk-agent
- 仓库名称：peririsk-agent
- 说明：围术期风险评估演示项目，输入患者基本信息和生命体征，程序先自行计算 ASA 麻醉分级与心率，再调用 DeepSeek 大模型生成术前风险评估报告。

## 仓库内容（详见 README.md）

- 公共模块：asa_risk.py（ASA 规则引擎）、patient.py（患者档案）、llm.py（DeepSeek 调用）
- 主程序：peririsk_agent.py（Agent 版，主推）、app.py（Streamlit Web 界面）、evaluate.py（离线批量评估）
- 数据：`data_cases/` 中 20 个 VitalDB 病例，每个包含 `waveform_120s.csv` 与 `numeric_120s.csv`
- 截图：images/ui_thinking.png、images/ui_report.png

## 本地运行

```bash
pip install requests scipy numpy matplotlib streamlit
# 在 config.py 填入 DeepSeek API Key
python peririsk_agent.py            # 命令行 Agent
python -m streamlit run app.py      # Web 界面
python evaluate.py                  # 离线批量评估
```

注意：config.py 已被 .gitignore 排除，不提交、不写死任何密钥。
