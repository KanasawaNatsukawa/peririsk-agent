# 原创性与新增贡献说明

## 一、既有基础

PeriRisk Agent 来自团队既有围术期风险评估演示原型。既有基础包括：单一或少量演示波形、查病历/心率/ASA 三工具、简化 ASA 规则、命令行与 Streamlit 展示。

## 二、本次新增贡献

本次提交版本相较既有原型新增或重构了：

- 五工具 Agent 编排：病历、数据质量、自动选窗心率、窗口稳定性、ASA 规则；
- 20 个 VitalDB 病例，每个 120 秒原始 PPG；
- 13 个候选 60 秒窗口的质量与稳定性选窗；
- 数字孪生推演、质量热力图和选窗策略对比；
- BMI、活动性肿瘤、急诊 E 标识和困难气道等 ASA 输入；
- 报告章节、禁止字段与“依据”格式的程序化校验；
- 20 例完整 Agent 评估、260 个候选窗口评估和 42 项自动测试；
- 比赛 PPT、技术说明、数据声明和可复现提交包。

Git 历史、开发日志、决策记录和测试演化记录保存在仓库中，可作为持续开发过程证据。

## 三、第三方代码与依赖

仓库未复制或合入其他团队项目的源代码。运行时使用 NumPy、Pandas、SciPy、Requests、Streamlit 和 VitalDB 客户端等开源依赖，通过 `requirements.txt` 安装；各依赖许可证见《第三方依赖与许可证》。

按仓库内实际提交的源码计算，copied third-party source code 占比为 0%。第三方依赖作为运行时库使用，不计入团队自行编写的 Agent、工具链和业务规则代码。

## 四、生成式 AI 辅助说明

团队负责提出真实问题、确定产品方向、工具边界、ASA 简化规则、测试标准、数据口径和最终验收。开发过程中使用生成式 AI 编程助手辅助代码起草、重构、文档整理和问题排查。

所有 AI 辅助产生的内容均经过仓库测试、评估和团队确认后才进入提交版本。团队不会将外部团队代码、商业闭源代码或来源不明代码声称为自主实现。

如组委会对生成式 AI 辅助开发有进一步披露要求，团队应按组委会最终口径补充说明。

## 五、数据与用途

病例人物档案为合成的演示信息，PPG 波形来自 VitalDB 公开数据。项目仅用于比赛与教学演示，不是医疗器械，不构成医疗建议，也不宣称临床准确率。
