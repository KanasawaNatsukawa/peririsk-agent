# 第三方依赖与许可证

项目未复制第三方项目源代码，以下依赖通过 `requirements.txt` 安装。

| 依赖 | 当前开发版本 | 许可证 | 用途 |
|---|---:|---|---|
| NumPy | 2.5.3 | BSD-3-Clause 及分发包内附带许可证 | 数值计算 |
| Pandas | 3.0.6 | BSD-3-Clause | CSV 数据处理 |
| Requests | 2.34.2 | Apache-2.0 | DeepSeek HTTP API |
| SciPy | 1.18.1 | BSD-3-Clause 及分发包内附带许可证 | PPG 峰值检测 |
| Streamlit | 1.66.0 | Apache-2.0 | Web 界面 |
| VitalDB | 1.7.2 | MIT | 公开生理数据读取脚本 |
| DeepSeek API | 在线服务 | 以 DeepSeek 官方服务条款为准 | 报告生成与工具调度 |

项目自身按 Apache-2.0 发布，根目录 `LICENSE` 保存许可证全文。

VitalDB 数据通过官方公开接口获取，仅用于演示、评估与展示；项目不重新分发模型权重，不使用商业闭源代码。
