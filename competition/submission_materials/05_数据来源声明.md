# 数据来源与合规声明

## 一、公开数据集

| 数据 | 来源 | 说明 |
|---|---|---|
| 脉搏波数据（20 × `waveform_120s.csv`） | VitalDB（公开生理数据集） | 真实脉搏波，每例 120 秒，500Hz |
| 监护仪数值心率（20 × `numeric_120s.csv`） | VitalDB（公开生理数据集） | 同窗口监护仪心率参考 |

- VitalDB 为公开学术数据集（https://vitaldb.net ），项目通过官方公开接口 `https://api.vitaldb.net/1.0.1/{case_id}.vital` 获取 20 个病例，使用范围遵循 VitalDB 官方公开数据访问条款。
- 数据用于工程验证和展示，未用于模型训练；心率参数搜索只在本地运行。

## 二、数据规模与处理范围

- 病例数：20；
- 每个病例截取连续 120 秒 PLETH，500Hz，共 60000 个采样点；
- 对应 `Solar8000/HR` 与 `Solar8000/PLETH_HR` 数值轨道作为同窗口参考；
- 运行时检查缺失值、幅度异常和起始基线稳定性，再从 13 个候选窗口中选取 60 秒；
- 参考心率不参与运行时选窗，只用于离线评估；
- 大赛评测集、测试集和答案分布未用于训练、调参或提示词设计。

## 三、敏感信息与合规

1. **无真实患者信息**：本项目病例均为基于公开数据与规则设定的示范病例（含虚构姓名），不涉及真实患者个人信息；
2. **脱敏原则**：如 DEMO 阶段引入真实病历数据，一律先脱敏处理，遵守个人信息保护相关要求；
3. **不泄露密钥**：演示材料与代码中不包含任何 API Key / 密钥，config.py 已被 .gitignore 排除；
4. **用途声明**：本项目为教学 / 演示用途，不是医疗器械，不构成医疗建议；ASA 分级逻辑为简化演示版，与临床完整标准存在差异。

## 四、原创性与第三方代码

- 本项目代码为原创实现，第三方依赖仅使用公开开源库（requests / scipy / numpy / matplotlib / streamlit）；
- 如 DEMO 阶段接入 openJiuwen / WorkSwarm 生态组件，将按生态开源许可要求声明来源与许可。
